# Sistema de Gerenciamento de Companhias Aéreas

Um sistema de gerenciamento de companhias aéreas desenvolvido em C# como aplicação de console, com o objetivo de praticar programação orientada a objetos e conceitos de desenvolvimento de software.

## Sobre o Projeto

Este projeto é um sistema de gerenciamento de companhias aéreas desenvolvido em C# como aplicação de console.

O sistema permite gerenciar passageiros, voos, aeronaves e reservas por meio de operações CRUD (Criar, Consultar, Atualizar e Excluir).

A aplicação utiliza o Entity Framework Core para interagir com um banco de dados SQL Server, garantindo a persistência dos dados e permitindo praticar conceitos de programação orientada a objetos e integração com bancos de dados.

## Objetivos

* Praticar os fundamentos de C# e os conceitos de programação orientada a objetos
* Implementar operações CRUD para passageiros, voos, aeronaves e reservas
* Integrar uma aplicação C# a um banco de dados SQL Server
* Utilizar o Entity Framework Core para acesso e persistência de dados
* Desenvolver a lógica de programação e a organização de projetos

## Tecnologias

* Entity Framework Core
* SQL Server
