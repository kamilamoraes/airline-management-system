# Planejamento — Airline Management System

## Objetivo

Desenvolver um sistema de gerenciamento de uma companhia aérea em C#, simulando operações básicas relacionadas a voos, passageiros, aeronaves e reservas.

O projeto será desenvolvido progressivamente, com foco no aprendizado de C#, Programação Orientada a Objetos e organização de software.

## Funcionalidades planejadas

### Passageiros

- Cadastrar passageiro
- Listar passageiros
- Buscar passageiro

### Voos

- Cadastrar voo
- Listar voos
- Buscar voo

### Aeronaves

- Cadastrar aeronave
- Listar aeronaves

### Reservas

- Criar reserva
- Consultar reservas
- Cancelar reserva

> Novas funcionalidades poderão ser adicionadas conforme o desenvolvimento do projeto.

## Entidades e dados

### Passageiro

- ID
- Nome
- CPF
- E-mail
- Telefone

### Voo

- Número do voo
- Origem
- Destino
- Data
- Horário

### Aeronave

- ID
- Modelo
- Capacidade
- Matrícula

### Reserva

- ID
- Passageiro
- Voo
- Data da reserva
- Status

## Conceitos a serem praticados

- Fundamentos de C#
- Programação Orientada a Objetos
- Classes e objetos
- Encapsulamento
- Métodos
- Coleções
- Relacionamento entre objetos
- Organização de código
- Tratamento de entradas e erros

## Desenvolvimento

O sistema será desenvolvido de forma incremental. Novos conceitos e funcionalidades serão adicionados conforme o aprendizado de C# evoluir.
